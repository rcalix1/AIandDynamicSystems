# Orbital Rendezvous with Neural Input Optimization (NIO)

## The Problem

We consider the classical orbital rendezvous problem framed as a trajectory-level inverse control task.

A **chaser object** must apply control inputs (thrust) to intercept a **target object** in orbit.

The goal is to use **Neural Input Optimization (NIO)** to compute the sequence of control inputs that drives the chaser trajectory to match the target trajectory.

---

## Dynamics (Clohessy–Wiltshire / Hill’s Equations)

Relative motion in orbit is governed by:

$$
\ddot{x} = 3n^2 x + 2n \dot{y} + u_x
$$

$$
\ddot{y} = -2n \dot{x} + u_y
$$

$$
\ddot{z} = -n^2 z + u_z
$$

State vector:

$$
x = [x, y, z, v_x, v_y, v_z]
$$

Control input:

$$
u = [u_x, u_y, u_z]
$$

Where:

* $n$ = orbital mean motion (constant)
* $u$ = control thrust (to be optimized)

---

## Objective

### Final Intercept (2-Point Matching)

Drive the chaser to match both **position and velocity** of the target at time $T$:

$$
\mathcal{L} = ||x_T - x_{target,T}||^2
$$

Expanded:

$$
\mathcal{L} = ||p_T - p_{target,T}||^2 + ||v_T - v_{target,T}||^2
$$

---

### Trajectory Matching (Stronger Formulation)

$$
\mathcal{L} = \sum_{t=0}^{T} ||x_t - x_{target,t}||^2
$$

---

## NIO Formulation

We solve:

$$
\min_{u_{0:T}} \sum_{t=0}^{T} ||x_t(u) - x_{target,t}||^2
$$

subject to:

$$
x_{t+1} = f(x_t, u_t)
$$

---

## Algorithm (Core Loop)

1. Initialize control sequence $u_{0:T}$
2. Rollout dynamics forward
3. Compute trajectory loss
4. Backpropagate through time
5. Update control inputs

Pseudo-code:

```python
u = torch.zeros(T, 3, requires_grad=True)

for i in range(num_iters):
    x_traj = rollout(dynamics, x0, u)
    loss = trajectory_loss(x_traj, target_traj)

    loss.backward()

    u = u - lr * u.grad
    u = u.detach().requires_grad_(True)
```

---

## Data Generation (No Dataset Needed)

Target trajectories are generated by simulation.

### Step 1: Sample target initial state

```python
x0_target ~ random
```

### Step 2: Generate target trajectory (drift)

```python
u_target = zeros(T, 3)
target_traj = rollout(dynamics, x0_target, u_target)
```

### Step 3: Sample chaser initial state

```python
x0_chaser ~ random (far from target)
```

---

## Interpretation

This problem is a **trajectory-level inverse problem**:

> Find control inputs such that the resulting trajectory satisfies a terminal or path constraint.

NIO enables solving this via gradient-based optimization over control sequences.

---

## Key Insights

* Intercept = matching **state in phase space** (position + velocity)
* Control is distributed over time (sequence optimization)
* Backpropagation occurs through the entire trajectory
* No dataset is required — trajectories are generated

---

## Extensions

* Add control penalty:

$$
\mathcal{L} = ||x_T - x_{target}||^2 + \lambda \sum ||u_t||^2
$$

* Add constraints on thrust magnitude
* Use learned dynamics instead of analytical equations
* Extend to multi-agent trajectory coordination

## One-Line Summary

> Use Neural Input Optimization to compute thrust sequences that drive a dynamical system to intercept a target trajectory in orbital motion.
